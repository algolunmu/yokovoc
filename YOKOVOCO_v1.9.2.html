Presets are saved in this browser's local storage, not inside the NSX-39. Apply one after each hardware restart or export a backup.

The bank starts empty. Only your saved presets appear here. Loading changes the on-screen settings; select APPLY ALL TO MIKU to send them to the device. Export JSON backups for safekeeping.

MIDI settings

Choose the MIDI input, output, and channel in the connection strip above the mixer. The input must have a real SysEx return route from Miku for lyric readback.

Channel 1 is normally Miku's vocal part. A MIDI output connection alone cannot read the flash; Miku's MIDI replies must reach the selected MIDI input.

Diagnostics

Logs MIDI sent and incoming device replies. No data is uploaded to a server.

How to run on iPad 6

Use an iOS browser that implements Web MIDI with SysEx. Ordinary Safari support varies; test with the Web MIDI Browser app by Takashi Mizuhiki. For reliable permissions, host this file at an HTTPS address (for example GitHub Pages), then open it in the browser and press Connect MIDI.

Suggested routing: iPad 6 → Lightning USB host adapter → H2MIDI → Pocket Miku. Select the actual output port, not a disconnected virtual port. Avoid sending FX SysEx while Xequence's clock is running until you've tested stability.

Supported: CC1, CC7, CC10 on GM channels, CC11, CC91, CC93 and CC94 (system variation), XG processor choice, supported drive/threshold and fixed-combination parameters, slot 00–15 lyric writing/reading, user presets and JSON backup. Limitation: Per-channel settings are stored locally and are not read back from Miku. The insertion effect targets Miku channel 1 regardless of the selected mixer channel. Miku has one selectable XG Variation algorithm at a time; internal multi-stage combinations are fixed order. Unsupported individual controls are disabled. Real NSX-39 testing is still necessary for specific optional algorithms and effect timing.
